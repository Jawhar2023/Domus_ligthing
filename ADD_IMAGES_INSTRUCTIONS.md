# Adding Showroom Images

To display your real store images on the website:

1. **Copy your images to `src/assets/` folder:**
   - Your storefront image → rename to `showroom-exterior.jpg`
   - Your interior LED lighting image → rename to `showroom-interior.jpg`

2. **The images will automatically appear on:**
   - Showroom page (hero section and gallery)
   - About page (showroom section)

3. **Image requirements:**
   - Format: JPG or PNG
   - Recommended size: 1920x1080px or larger
   - File names must match exactly: `showroom-exterior.jpg` and `showroom-interior.jpg`

The website is already set up to use these images - just add them to the assets folder!
